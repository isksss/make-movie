# Git 運用

## ブランチ

- `main`: 本番
- `develop`: 開発統合
- `feature/<issue-number>-<summary>`: 機能開発
- `hotfix/<summary>`: 緊急修正

## Commit Message

Conventional Commits を使います。本文は日本語で書きます。

```text
feat(project): Projectモデル追加
fix(plugin): WASMロード不具合修正
docs(architecture): Plugin設計更新
```

## Pull Request

PR 本文は日本語で書きます。
